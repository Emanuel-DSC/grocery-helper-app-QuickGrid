# 🛒 QuickGrid — Grocery Helper App

A Flutter mobile application designed to simplify grocery shopping by organizing items into categories and allowing users to reuse their shopping lists efficiently.

## ✨ Technologies & Architecture

### Tech Stack
- `Flutter`
- `Dart`
- `Provider`
- `GetStorage`

### Architecture & Concepts
- Global state management using Provider
- Lightweight, fast local data persistence with GetStorage
- Dynamic Theme management (Light & Dark mode support)
- Clean, high-contrast, and modular UI structure

## 🚀 Features

- **Smart Categorization:** Create structured grocery lists divided into clear, scannable categories.
- **Active Shopping Mode:** Easily mark and track items as purchased in real-time.
- **Reusable Templates:** Save and clone entire shopping lists to skip rewriting items for future shopping cycles.
- **Tailored Experience:** Full native support for both Light and Dark mode to adapt to any environment.
- **Accessible Design:** Minimalist layout built for effortless one-handed navigation and quick interactions.

## 📍 The Process

The creation of **QuickGrid** driven by a deep personal purpose. My mother used to write down grocery lists on paper before every shopping trip. However, after undergoing hand surgery, writing manually became a painful and difficult task for her. To simplify her routine, increase her autonomy, and eliminate the physical strain of paperwork, I designed and built this application.

Because the focus was to make her life easier, the development required a strong emphasis on **User Experience (UX) and Accessibility**. I utilized **Provider** for clean state management to ensure immediate UI feedback, and **GetStorage** for efficient, lightweight local persistence—meaning her lists are safely cached on her device without requiring a complex cloud backend. Designing a system with high-contrast text, clear check-states, and intuitive mechanics allowed me to build a practical product that perfectly fits real-world accessibility needs.

## 🚦 Running the Project

1. Clone the repository: `git clone https://github.com/Emanuel-DSC/QuickGrid.git`
2. Install dependencies: `flutter pub get`
3. Ensure you have an active emulator or device connected
4. Run the application: `flutter run`
