# 🛒 Grocery Helper App (QuickGrid)

A Flutter mobile application designed to simplify grocery shopping by organizing items into categories and allowing users to reuse their shopping lists efficiently.

<br>

## 🚀 Features

* Create categorized grocery lists
* Mark items as purchased
* Save lists for future shopping cycles
* Clean and intuitive user interface
* Light and Dark mode support

<br>

## 🛠 Tech Stack

Flutter • Dart • Provider • GetStorage

<br>

## 🧠 Architecture

* State management using Provider
* Modular project structure
* Local persistence with GetStorage
* Theme management (Light/Dark mode)
